# 日々戯画 (HibiGiga)

「鳥獣戯画」の絵巻物テイストで、自分の日常をコミカルな日記として記録できる、デスクトップ＆タブレット向けペイント＆コラージュ日記ツール。

## 🚀 開発環境の構築方法

本作は **Tauri v2 (Rust × TypeScript)** で開発されています。

### 前提条件
以下のツールをあらかじめローカル環境にインストールしてください。
- **Rust**: `rustup`（最新のStable版）
- **Node.js**: `v20` 以上 (推奨)
- **パッケージマネージャー**: `pnpm` (推奨) or `npm` / `yarn`
- **OS固有の依存関係**:
  - **macOS**: `Xcode Command Line Tools`
  - **Windows**: `WebView2`, `Visual Studio 2022 (C++によるデスクトップ開発)`
  - **Linux**: `glib`, `webkit2gtk-4.1` 等（詳細はTauri v2ドキュメント参照）

### 1. リポジトリのクローンと初期化
```bash
git clone https://github.com/Toshiaki0315/HibiGiga.git
cd HibiGiga
pnpm install
```

### 2. 開発サーバーの起動 (Live Reload)
```bash
pnpm tauri dev
```

## 🧪 テスト駆動開発 (TDD) & カバレッジ90%維持ルール

本プロジェクトでは、すべての機能開発において **TDD（Test-Driven Development）** を採用し、常に**カバレッジ90%以上**を維持します。

### A. フロントエンド (TypeScript / Vitest)
テストは `vitest` を使用して、仕様に対するテストを記述してからロジックを実装します。

- **テスト実行**: `pnpm test`
- **カバレッジ測定**: `pnpm test:cov` (カバレッジが90%を下回る場合はコミット対象外とします)

### B. バックエンド (Rust / Cargo)
`src-tauri/src` のRustロジック（日記保存、古風自動翻訳、ファイルI/Oなど）は、単体・統合テストを必ず並行して作成します。

- **テスト実行**: `cargo test`
- **カバレッジ測定 (MacOS/Linux)**: `cargo tarpaulin` または `cargo llvm-cov` を使用
  ```bash
  cargo llvm-cov --all-features --html
  ```

## 🎨 ソフトの使い方 (仕様)

1. **無限絵巻物の展開**: アプリ起動後、画面を横に「ころころ」とスクロール。過去の日記が1本に繋がった絵巻物のようになります。
2. **ドラッグ＆ドロップ**: 左側の「素材（アセット）ライブラリ」からカエルやウサギ、現代風アイテム（スマホやPCなど）を選んでキャンバスに配置。
3. **筆のタッチ**: 水墨画風（にじみ・かすれ）のデジタルブラシで手描き、または「落款」スタンプを押す。
4. **自作スタンプの取り込み**: 素材ライブラリの「自作」タブから PNG / JPEG / WebP 画像を取り込み、「そのまま」または「墨絵風」のスタンプとして使えます。
   - 取り込み時に長辺 1024px へ縮小し PNG に再エンコードするため、写真の撮影位置 (GPS) などの EXIF 情報は保存されません。
   - 画像と日記は OS のアプリ用データフォルダ（macOS: `~/Library/Application Support/com.hibigiga.app/`）に保存され、**リポジトリ（GitHub）には含まれません**。
5. **自動古風変換**: 日記入力欄に「今日も仕事が忙しかった」と打つと、自動で「本日も職務多忙を極めたり」のような味わい深い古風なテキスト＆フォントに変換され、吹き出しとして画面に反映されます。
